# Vijeth Balasubramaniam — Research Portfolio

This is the GitHub Pages website repository, not just a prototype. It presents ten projects as concise research stories and includes report-derived visual evidence, original project source files and supporting reports.

## Publish on GitHub Pages

1. Back up the current `Vijeth-ML/vijeth-ml.github.io` repository.
2. Extract this package and upload **the contents of this folder** to the repository root (not the enclosing folder). `index.html` must sit at repository root.
3. Commit to `main`; keep GitHub Pages configured for `main` / root.
4. Replace `ADD-YOUR-EMAIL` in `index.html` with the email address you want public, or remove that link.
5. Preview the published site and check all evidence images.

## Evidence and research integrity

Images in `assets/project-evidence/` are rendered from the original project reports, with report page numbers in captions. They are documentary evidence, not newly generated plots. Where a report page contains a table or chart, the full page is shown to preserve its context. Historical metrics are not presented as independently reproduced results.

Project originals are retained under `projects/<project-id>/original/`. The site knowledge base is `data/projects.js`; evidence metadata is `data/evidence.js`. Update project narratives only after checking the corresponding source and report.

## Chatbot

The current assistant is a browser-only conversational guide based on the curated project knowledge base. It is not a hosted LLM and does not access arbitrary GitHub content. Unmatched questions are redirected to relevant external resources.
