# Contributing to this portfolio

This is a personal learning and research portfolio. Improvements should make the work more accurate, reproducible, accessible or easier to understand.

- Prefer small commits with clear messages, e.g. `docs: explain EMNIST preprocessing`.
- Do not add fabricated metrics, empty activity commits or copied material without attribution.
- Keep datasets and generated artefacts out of Git unless there is a clear licence and reason to version them.
- Never commit credentials, tokens, private records or restricted coursework.
- Use issues or TODOs to record a genuine next step.
